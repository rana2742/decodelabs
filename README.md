# Linux Commands Practical

## Overview

This repository contains a practical demonstration of commonly used Linux commands. The objective of this exercise was to gain hands-on experience with Linux file system navigation, file management, permissions, user administration, and package management.

## Topics Covered

### 1. Directory Navigation

* `pwd`
* `cd`
* `cd ..`
* `cd ~`

### 2. File and Directory Management

* `mkdir`
* `touch`
* `rm`
* `rmdir`

### 3. Viewing Files

* `cat`
* `less`

### 4. File Permissions and Ownership

* `chmod`
* `chown`

### 5. User Privileges

* `sudo`
* Root user access

### 6. Package Management

* `apt update`
* `apt install`

### 7. Linux File System Structure

* `/bin`
* `/boot`
* `/dev`
* `/etc`
* `/home`
* `/root`
* `/tmp`
* `/usr`
* `/var`

## Learning Outcomes

After completing this practical, I was able to:

* Navigate the Linux file system efficiently.
* Create, modify, and delete files and directories.
* Manage file permissions and ownership.
* View and search file contents using terminal commands.
* Understand the purpose of important Linux system directories.
* Perform basic administrative tasks using elevated privileges.
